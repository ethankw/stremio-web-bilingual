# 片库“隐藏已观看”开关

片库不再提供“已观看 / 未观看”排序 chips。旧的 `sort=watched`、`sort=notwatched` 链接按普通片库排序加载，不保留隐式过滤。其余排序、影片身份、观看记录与详情链接保持不变。

片库与发现页各有一个默认关闭的开关，使用固定 localStorage key 分别保存状态，不依赖发布 SHA。开关用 Core 输出的 `watched === true` 控制卡片显隐，复用发现页的缩放和位移动画；关闭后恢复原位置。不按播放进度推断已观看，不修改观看标记。受限存储仍可在当前会话使用开关。

隐藏卡片填满已载入页、或剩余可见项目不足以产生滚动时，仅在片库是当前页面时继续读取下一页；不会把“这一页全看过”误称为“片库没有未看过的影片”。保留其他排序的顺序和 Core 分页，不再依赖旧 watched/notwatched 排序的连续分组行为。
