# 发现页选择与资料顺序

2026-10-16，按用户要求调整。

- 发现页普通单击海报只选择该影片并展示预览；重复单击已选影片不进入详情页。
- 双击海报进入被双击影片的详情页，不依赖之前选中了哪部影片。
- 手机单击仍打开已有预览面板，面板中的详情入口继续可用。键盘可选择影片并使用预览中的详情按钮；修饰键打开链接保留浏览器行为。
- 共享资料预览中的中英文简介都在演员、导演之前；类型等其他资料保留在原位置。关闭双语或缺少翻译时，原文简介同样在演职员之前。
- 首页、搜索及片库的海报点击逻辑不作调整；不写入账号、片库、插件配置或观看记录。

## 行为验收

在专用浏览器页面分别检查：单击未选海报、再次单击已选海报、双击已选海报、双击未选海报；确认路由、选中影片与预览内容。检查中英文简介和演员／导演的实际顺序，以及窄屏预览和其他页面的原有详情入口。

合成资料用于展示层回归时必须与真实线上验收分开记录，不将构建或模拟数据结果当作真实账号功能通过。线上使用入口保持 https://stremio2.ethankw.workers.dev/ 。
