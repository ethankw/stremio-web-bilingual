# 列表层级、类型筛选与简体中文校对

本次调整只涉及本 Fork 的显示层和中文资源，不改变影片身份、插件安装、账号数据、播放进度或本机 Stremio 配置。

- 双语卡片标题间距从 0.05rem 增至 0.3rem；中文标题透明度为 0.7。
- 电影和剧集卡片预留一致文字区，新增更小、更灰的年份与 IMDb 评分行。年份读取原始 releaseInfo/released，评分读取原始 IMDb 链接或明确的 imdbRating，不使用 TMDB 评分。缺少字段时只显示可用字段；片库项目若未携带这类资料，保持空缺，不发起额外猜测查询。
- 发现页的 genre 选项完整展开为自动换行的按钮 chip。默认空筛选显示“全部”，动作、冒险等仍使用原插件深链导航；Enter/Space 可操作，aria-pressed 表示当前选择。类型不再重复放在筛选弹窗中，其他筛选保留。
- 简体中文采用本仓库 src/locales/zh-CN.json，覆盖锁定上游英文包的全部 2,076 键；本项目独有文案另存 zh-CN-extra.json。品牌、快捷键、技术名称保留原名。保持其他语言资源和依赖不变。
- 资源测试检查键覆盖、普通英文残留、变量/HTML/换行格式与关键语义回归。人工校对补充自动检查无法判断的按钮语态、播放进度、剪贴板及账号授权等含义。

使用方法：中文界面下打开“发现”，点击类型 chip 筛选，点击“全部”清除类型；卡片第三行可查看插件提供的年份和 IMDb 评分。英文和中文标题仍遵循本项目设置中的标题顺序。

回滚：对本功能提交正常 revert 后重新构建，沿原私人预览、个人入口流程发布；或将 Worker 回滚到本次发布前的版本（在任务 outputs 发布回执记录具体 UUID）。本次回滚不涉及凭证、Access 策略、账号或 Stremio 服务。
