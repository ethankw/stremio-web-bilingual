# 统一英文海报及演职员展示

2026-10-15 用户要求同一影片在整个应用采用相同展示逻辑。此规则取代此前“保留各插件海报与姓名”的决定。

## 共用规则

- 可靠 movie/series + IMDb 或 TMDB ID 解析为同一 TMDB 影片身份。元数据请求显式 language=en-US，并 append_to_response=images；不对每张卡片另加一轮图片请求。
- 海报、Logo、背景先选图片记录中 iso_639_1=en 的版本，再选 iso_639_1=null 的无文字版本；不把默认 poster_path 或中文图片宣称为英文。按票数、评分、尺寸、路径稳定排序，相同片在不同编号/目录得到同一选择。字段缺失、图片损坏或请求失败时使用占位/纯背景，双语文字和原业务操作仍可用。
- 只有固定 TMDB 图片域名、明确尺寸与经过验证的文件路径可进入共用展示层。未知/不支持的身份及用户关闭增强时保留原始展示，绝不按片名猜海报。
- 演员、导演使用同一个 language=en-US credits 结果，保持 TMDB 信用顺序，各展示最多 10 位，按人物 ID 去重。姓名采用英文资料的规范姓名，不自行翻译或音译，不使用插件的中文姓名覆盖。英文资料中也可能缺少罗马化姓名，不伪造。
- 照片按当前片和角色的已知人物 ID 对应，不因重名配错头像。人物 chip 的搜索统一使用该规范姓名；类型、IMDb、分享等非人物链接不变。
- 查询未完成或英文 credits 不可用时，不短暂露出插件的另一套中文演员名单；其他资料和资源列表不阻塞。

## 接入入口

MetaItem 覆盖首页行、发现、搜索、片库和继续观看的海报。MetaPreview 覆盖桌面/手机预览、详情及播放器侧栏的 Logo、背景和演职员。详情外层背景使用同一选择器。

日历的表格海报及单集卡片的海报回退使用 CanonicalPoster，共用同一规则；父级身份仅从核心明确给出的详情路由读取，不从视频 ID 猜父片。单集剧照和普通视频缩略图属于内容画面，不强行替换成影片海报。

## 验证

268 tests / 15 suites，包括中英文插件输入得到相同规范演职员、IMDb/TMDB 两条路径得到相同海报和演职员、英文/无文字/中文图优先级、非法图片拒绝、日历明确父级路由与不猜视频 ID。原匹配、双语、观看过滤及片源回归通过。

独立浏览器以插件原始中文演员/导演及中文海报为输入，用真实本地 Worker 查询 TMDB。IMDb 与 TMDB 两个目录选中相同英文海报，显示相同 10 位演员及两位导演，详情中的中文人物 chip 为零，头像、英文 Logo 和背景实际加载。日历入口由共用函数行为测试及生产编译覆盖，未声称真实账号日历已逐页验收。

依据：[TMDB 图片语言及 fallback](https://developer.themoviedb.org/docs/image-languages)、[Append To Response](https://developer.themoviedb.org/docs/append-to-response)。只设置 language=en-US 不足以证明默认海报为英文，因此使用逐张图片的语言证据。
