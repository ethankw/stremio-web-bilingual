## 首页版本更新修复（2026-10-16）

首页 HTML 不进入 Service Worker 预缓存，并通过 `_headers` 禁止 HTTP 缓存；带 SHA 的静态资源仍可预缓存。新 Service Worker 自动激活，不主动 claim 其他页面；已有页面提供手动重新加载入口，不因被动更新事件自动刷新。每次打开都会检查 Worker 更新。

旧版曾缓存首页，首次迁移仍可能先打开旧首页。检测到新版后使用“重新加载用户界面”，或者在当前页强制刷新一次。安装新缓存策略后，普通重新打开或刷新直接取得服务器的首页，不需要清除登录、插件、片库或观看记录。

验收必须覆盖：先安装真实旧版缓存，再部署新文件、普通重新加载、验证代码 SHA 和首页缓存项；之后更换首页再次普通刷新，验证新 HTML 可见。另一个已有页面不应自行重新加载。禁止用 DevTools 的 Service Worker bypass 代替此验收。
