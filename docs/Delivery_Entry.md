# 固定交付入口

用户于 2026-10-15 明确指定唯一使用和验收地址：

**https://stremio2.ethankw.workers.dev/**

- 正式 Worker：`stremio2`。发布配置：`wrangler.personal.jsonc`。
- 后续所有已完成修改都在这个地址交付。先完成本地测试、实际 UI 验证、提交和合并检查，再从干净的合并提交构建并发布；交付时核验同一地址的版本与实际功能。
- 内部可以使用本地或 preview 环境，但不再要求用户换域名、迁移账号状态来验收日常修改。不要将测试数据页面当成用户正式入口。
- 发布和功能验收分别记录。若权限或真实会话阻塞，完成不依赖它们的工作，明确剩余项；不使用构建成功代替功能验收。
- 只配置本项目的 Worker。保持私人保护，不开放 TMDB 凭证或接口给未授权访问者；不改变账户级保护或其他项目。
- 新建固定入口时先以双语功能关闭且无 Secret 的状态部署，完成该入口的 Access 保护和匿名拦截后，再通过安全终端流程配置已有 TMDB token、启用功能。
- 新域名与旧域名的浏览器状态隔离。用户可能需要在固定入口自行登录一次原 Stremio 账号。不要通过复制 token、浏览器存储或重装插件来迁移；不得改动原有账号插件和观看记录。
- 旧入口暂留作历史和回滚依据，不自动删除、不开放访问保护，不再作为新的用户交付链接。
- 回滚保持同一固定地址，回退该 Worker 的已知正常版本。首次初始化没有旧版本可回退时，关闭双语功能并保持保护；不删除用户数据或 Worker。

该约定取代早期“让用户先去 preview、再去 personal”的交付方式。任何后续变更入口的决定必须由用户明确指定。
