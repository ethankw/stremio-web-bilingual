# 设置与字幕偏好保存

固定入口仍为 https://stremio2.ethankw.workers.dev/ 。状态属于当前浏览器和此站点，不能自动跨域、跨浏览器复制。

## 设置恢复

Stremio Core 的 profile 仍是主要设置存储。Core 初始化完成后，在显示页面前恢复同账号的设置恢复副本；每次明确 UpdateSettings 成功后，再保存已实际生效的设置。恢复 key 不含版本号或构建 SHA，仅有数据 schema 版本。新增 Core 字段保留其当前值。

恢复副本仅包含列出的界面、播放、字幕等标量偏好，并校验类型与长度。账号凭证、插件配置、服务器 URL、remote HTTPS 地址均不复制。不同账号的副本隔离。损坏、禁用或写满的浏览器存储不阻止 Core 正常启动。

这不会声称已证实每次升级都会重置设置：旧版普通刷新也能保留默认字幕语言；恢复逻辑另以模拟 Core 设置回到默认值的升级回归测试验证。

## 字幕自动选择

字幕开/关独立保存于稳定的浏览器 key。未选择过开关时，按现有默认字幕语言是否为空迁移初始开关；之后选择“关闭”或具体字幕都会明确保存开关状态。关闭状态跨影片和重载保留，首选语言不会因关闭而丢失。

开启时：首选语言优先，其次英语，再选其他可用字幕（含未知语言）。内嵌和外挂字幕都参与；地区语言标签也按基础语言匹配。历史影片的轨道 ID 或语言不能覆盖全局首选语言。首选字幕晚于 fallback 返回时可以自动升级到首选；当前影片中明确手选字幕后，不再被后台返回结果覆盖。

浏览器直接播放 URL 时，由应用显式注册片源自带的字幕，避免视频库在直播放路径中丢失它们。没有任何字幕时保持视频可播放，不伪造字幕。添加本地字幕视作明确选择，并开启字幕。

## 验证

覆盖开关独立保存、关闭状态恢复、受限存储、账号隔离、设置升级恢复、不备份凭证，以及字幕首选/英语/其他语言/无字幕和晚到字幕的优先级。真实播放器使用匿名本地生成的测试视频验收，不为测试播放账号片库或修改观看记录。全量前端 tsc 的既有诊断需与当前稳定提交对比，不将构建通过冒充全量类型检查通过。
